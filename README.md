Name: FIT LOG

📋Project Description:FitLog is a fitness-related web application that helps users manage their daily workouts. Users can explore different exercises, see workout details, and add exercises to their daily plan.

The app shows useful information such as workout time, calories, equipment, and difficulty. Users can also save exercises for later and manage their workout plan from the My Plan page.

FitLog helps users organize their workouts, manage their time, and maintain a healthy fitness routine.



Technologies: 1. NEXT.JS
              2. Daisy.ui
              3. Tailwind CSS


 FitLog App Features: 
    🏋️ Workout Library — Explore different exercises and workouts.
    📋 Daily Workout Plan — Add workouts to today's plan and manage them     easily.
    💾 Save Workouts — Save exercises for later use.
    📱 Responsive Design — Works smoothly on mobile, tablet, and desktop devices.
    🔔 Toast Notifications — Get notifications when workouts are added or saved.
    ❎ Remove plan -Remove plan page for a Today's plan.
